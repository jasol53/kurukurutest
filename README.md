# 쿠루쿠루 V5 단일 그룹 버전

1. 기존 Supabase V5 테이블은 그대로 유지하세요. 기존 SQL을 다시 실행하지 마세요.
2. Supabase SQL Editor에서 `02-single-group.sql` 전체를 실행하세요.
3. Authentication → Providers → Anonymous Sign-ins를 켜세요.
4. GitHub Pages 저장소 루트에 `index.html`, `supabase-sync.js`를 덮어쓰세요. 나머지 파일은 기존 V5 그대로 사용 가능합니다.
5. 이름 입력 → 공개 동의 → 72문항 → 결과 보기 시 자동으로 '쿠루쿠루' 그룹 가입 및 저장합니다.

## 개인정보 주의
초대코드를 없애면 사이트에 접속한 누구나 익명 계정으로 그룹에 가입하여 기존 참가자의 이름과 점수를 조회할 수 있습니다. RLS는 그룹 외부 접근을 막지만, 공개 가입 그룹은 사실상 공개 열람과 비슷합니다. 진짜 멤버 6명으로 제한하려면 서버측 관리자 승인이나 별도의 접근 통제가 필요합니다.

기존 가입자는 같은 익명 계정이면 기존 그룹 소속을 유지합니다. 테스트 점수 저장은 결과 화면 진입 시 실행됩니다.
